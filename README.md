# ResolveDesk — Support Ticket Management System

ResolveDesk is a full-stack web application designed
to help teams create, assign, manage, and track
support tickets through a centralized interface.

## Live Demo
https://resolvedesk-jrax.onrender.com/login

## Technology Stack
- **Backend:** Java 21, Spring Boot, Spring Data JPA
- **Frontend:** Thymeleaf, HTML, CSS
- **Database:** PostgreSQL
- **Security:** Spring Security, BCrypt, role-based authorization
- **Testing:** JUnit, Mockito
- **Deployment:** Docker, Render, Neon
- **Build Tool:** Maven

## Key Features
- Create, update, assign, and track support tickets
- Manage ticket priorities, categories, and statuses
- Role-based access for administrators and employees
- Search and filter tickets
- View reporting dashboards and export CSV reports
- Input validation and authorization controls

## Testing
The application was developed with automated testing using JUnit and Mockito. The capstone evaluation documented 11 passing automated tests.

## Project Background
Developed as an individual software engineering capstone project at Western Governors University in October 2026. This repository is a portfolio showcase containing project information rather than the original coursework source code.
